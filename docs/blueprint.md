# **App Name**: UdhaarX

## Core Features:

- Role Selection: User role selection (customer/shopkeeper) on app launch.
- Details Capture: Capture customer details (name, mobile number) and shopkeeper details (shop name, shop address).
- Display QR: Display shopkeeper's QR code.
- Amount input by QR code: QR code scanner for customers to input udhaar amount, mimicking UPI functionality. When amount is captured, the information will populate a simple confirmation page with the names and amount, to be confirmed.
- Customer ID Generation: Customer unique ID generation and display to shopkeeper upon transaction.

## Style Guidelines:

- Primary color: HSL 49, 86%, 56% which converts to a bright gold (#F1C232), providing a feeling of fiscal responsibility, but not somberness.
- Background color: HSL 49, 15%, 97% which converts to a pale yellowish off-white (#FDFBF5) creating a light and clean background.
- Accent color: HSL 19, 65%, 49% which converts to a terracotta (#C77031). It is used for secondary buttons and important alerts.
- Headline font: 'Poppins', sans-serif. Body font: 'PT Sans', sans-serif.
- Simple, line-based icons to represent different actions.
- Clean and minimalistic design with a focus on readability.
- Subtle animations during QR code scanning.
